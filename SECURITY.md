# Security Policy

Report security concerns to s.shivang.jindal@fsksurat.in (GitHub private vulnerability reporting is also enabled). Please include reproduction steps; you will get a response within a few days.

This project has zero runtime dependencies, no install step, and no network access in its test suite. Report any supply-chain concern -- an added dependency, a lockfile appearing, a fetch inside tests -- as a security issue, since each would break the project core guarantee.
